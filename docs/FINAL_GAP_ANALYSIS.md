## Базовые проверки

- Backend: `10 passed`, одно предупреждение Starlette TestClient/httpx.
- Frontend: `npm run build` проходит.
- `/api/health` и локальный Vite отвечают HTTP 200; данные загружаются.
- Браузер при масштабе 100%: `visualViewport.scale = 1`; ошибок `error`/`warn` в консоли нет.
- Текущий демо-flow: E0001 → профиль → skill gap 16 → top-3 → roadmap → завершение → пересчёт.

## Решение по приоритетам

P0: activity details, рабочий AI Navigator на инструментах, fallback без ключей. P1: читаемый и разделённый dashboard, демо-статусы activity, дополнительные тесты, базовый OpenAI-compatible adapter. P2 остаются документированными без расширения проекта до LMS или системы авторизации.

## Остаточные ограничения

- Датасет не содержит реальных ссылок LMS, поэтому кнопка внешнего перехода показывается только при валидном `external_url`; в текущих событиях ссылка отсутствует.
- Прогресс, запись и старт хранятся только в памяти процесса. Нет авторизации, постоянного хранения, XP, STT/TTS или RAG. Это P2 для будущей интеграции.
- Режимы OpenAI/NVIDIA не проверялись с реальными ключами; подтверждены формат адаптера, fallback без ключа и ограничение вывода модели тестом с подменённым ответом.
- Pytest через системный Python невозможен из-за отсутствующего FastAPI; в `.venv` тесты проходят. Системный временный каталог pytest недоступен (`WinError 5`), поэтому используется `--basetemp .pytest_local` (игнорируется Git).
- Есть одно предупреждение Starlette TestClient/httpx о deprecated интерфейсе; на результат тестов не влияет.
