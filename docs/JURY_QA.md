# Короткие ответы жюри

| Вопрос | Ответ |
|---|---|
| Почему AI, а не просто правила? | В текущем демо ядро — детерминированная модель сопоставления навыков, цели и активностей. GPT и NVIDIA API не подключены. Не называем ранжирование обученной моделью. |
| Почему объяснимо? | У каждой активности есть пять частей score, совпавшие навыки, прогноз до/после и IDs источников. Расчёт воспроизводим. |
| Зачем LLM? | В текущем демо LLM не используется: Navigator отвечает через `TemplateAIProvider`. В коде есть опциональный адаптер для выбора формы ответа, но ключи не подключены и реальный вызов GPT не проверялся. |
| Где NVIDIA? | В текущем демо NVIDIA не используется. В коде есть опциональный адаптер, который потребовал бы `AI_PROVIDER=nvidia` и `NVIDIA_API_KEY`; интеграция с реальным API не проверялась. |
| Почему нет RAG? | Датасет структурирован и мал; добавление RAG усложнило бы источник фактов без выигрыша для этого MVP. |
| Почему нет своей LMS? | MVP показывает выбор и прогноз; запись/прохождение в интерфейсе симулируются, реальная интеграция — следующий этап. |
| Как защищаются персональные данные? | В демо используются синтетические записи. Для настоящих данных нужны авторизация, ограничение доступа, шифрование, аудит и согласование с банком; сейчас этого нет. |
| Как подключить LMS/HRIS? | Импортировать роли, навыки и историю через согласованный API/ETL; отправлять события завершения из LMS; затем добавить устойчивое хранилище и идентификацию. |
| Как мерить эффект? | Сравнить долю завершённых релевантных активностей, закрытие проверенных skill gaps, внутренние переходы и время до квалификации с контрольной группой. Пока полевых цифр нет. |
| Как масштабировать? | Вынести состояние из памяти, добавить БД, фоновые обновления данных, авторизацию и мониторинг. |
| Что работает и что симулируется? | Загрузка датасета, gap, score, roadmap, API, UI и перерасчёт работают; запись и завершение — сессионная симуляция. Голосового интерфейса и реальной LMS нет. |
| Чем отличается от каталога? | Показывает измеримый разрыв до выбранной роли, ранжирует доступные активности по нему и пересчитывает маршрут после шага. |
